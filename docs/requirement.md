## 本作业要求完成如下任务

1. 设计一个解释型的通用脚本语言，以你的名字命名（赵梓伊同学设计的语言命名为ZZY语言），并实现其解释器。ZZY语言至少支持以下基本功能：
   - 整数，字符串等基本数据类型
   - 数组，结构类型
   - 基本输入输出
   - 分支循环控制
   - 函数定义和调用

   注意：ZZY语言的语法可以自由定义，只要语义上要求即可，应该体现自己的特色，可以吸取各种语言的优点进行组合，但不能与现存的任何程序设计语言完全相同。

2. 编写ZZY语言的完整黑盒测试集实现自动测试。测试脚本使用ZZY语言编写，覆盖ZZY语言的所有功能。一个命令执行所有测试。
3. 使用ZZY语言设计一个用于性能测试的脚本进行性能测试，将测试结果与相同功能的python脚本的性能作比较。
4. 设计ZZY语言的开发指南（例如Skills等文档）供编程Agent使用，使得编程Agent能够使用ZZY语言顺利编写代码。
5. 使用编程Agent辅助，能够基于ZZY语言快速设计实现一个代码规模不少于200行的应用程序（功能完整，内容不限制，例如可以是一个小游戏，小工具等）。

## 开发环境要求

1. 实现解释器的程序设计语言没有限制
2. 编程Agent以及大模型的使用没有限制
3. 必须使用GIT进行版本管理

## 作业提交的内容

1. ZZY语言的语法规则文档
2. 能够执行ZZY语言的解释器源程序
3. ZZY语言的完整黑盒测试集
4. 对ZZY语言的性能测试报告
5. ZZY语言的开发指南文档以及给AI使用的文档
6. 编程Agent使用ZZY语言开发的应用程序源代码，编程Agent生成的开发记录
7. 所有工作的Git历史记录
8. 系统介绍PPT

## 作业验收

线下验收。学生按照任课教师或助教要求讲解PPT和部分实现细节以及相关演示，回答任课教师或助教的提问。

## 评分原则

依据验收表现以及交付物的内容评分，各部分内容分数占比如下：

1. ZZY解释器的实现（20分）
2. ZZY解释器的自动测试脚本（20分）
3. ZZY解释器的性能测试（10分）
4. ZZY语言的语法说明，给人和AI使用的开发指南（20分）
5. 利用编程Agent，使用ZZY语言开发程序（30分）
