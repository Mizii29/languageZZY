## 原人工方案发现的问题

原指南切到新的工作目录后直接用`.venv/Scripts/python.exe -m zzy`，没有指定仓库导入路径。实际在空目录、移除`PYTHONPATH`的子进程中导入到`.venv/Lib/site-packages/zzy`；该安装包11份源码与P11候选不同，包括interpreter/resources/features等。因此旧命令即使执行成功，也可能测的是旧包。

本次只修指南：保存原`PYTHONPATH`、显式设置为仓库根目录，测试前断言`zzy.__file__`来自项目并核对44份运行时哈希，结束恢复环境。最小复核确认来源变为仓库`zzy/__init__.py`，四个现有ZZY脚本从独立工作目录执行check均静默退出0，未创建窗口或SVG/项目文件。未修改`.venv`旧安装包、运行时代码或ZZY测试脚本；语法检查不作为M01/M02人工结果。
